# IP Tray

Небольшое Python-приложение в системном трее (область уведомлений панели задач).
Показывает внешний IP сразу с двух источников:

- [2ip.ru](https://2ip.ru/)
- [Яндекс.Интернетометр](https://yandex.ru/internet/)

Так видно, совпадают ли ответы сервисов (полезно при VPN / прокси).

## Возможности

- Иконка в трее: на ней последние октеты IP
- Подсказка при наведении: IP с 2ip, Яндекса и локальный адрес
- Правый клик: копировать IP, обновить, открыть сайты
- Компактное окно над панелью задач
- Уведомление, если внешний IP сменился
- Автообновление раз в 60 секунд
- Автозапуск с Windows (пункт в меню)

## Установка

Нужен Python 3.9+.

```bat
cd ip_tray
python -m pip install -r requirements.txt
python ip_tray.py
```

Чтобы не мелькала консоль, запускайте так:

```bat
pythonw ip_tray.py
```

или переименуйте файл в `ip_tray.pyw`.

## Сборка в .exe

Только на Windows, двойной щелчок по `build.bat`.

Или вручную:

```bat
python -m pip install -r requirements.txt pyinstaller
python -m PyInstaller --onefile --windowed --name IPTray --icon icon.ico ip_tray.py
```

Готовый файл: `dist\IPTray.exe`.
Автозапуск включается из меню иконки в трее.

## Как это устроено

- Яндекс: `https://yandex.ru/internet/api/v0/ip`
- 2ip: разбор страницы `https://2ip.ru/`
- Трей: библиотека `pystray`
- Окно: стандартный `tkinter`

Иконка зелёная, если оба сервиса вернули один IP, и оранжевая, если адреса разошлись.
